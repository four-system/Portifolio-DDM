# Projeto – Site de Lista de Tarefas

## Objetivo do projeto

O objetivo do projeto foi desenvolver um *site de lista de tarefas*, permitindo que o usuário cadastre, visualize e exclua tarefas de forma simples.

O projeto foi desenvolvido colocando em prática conhecimentos de desenvolvimento web e lógica de programação, trabalhando principalmente com a criação da interface, organização dos elementos, funcionamento dos botões e armazenamento das tarefas.

A ideia principal foi criar uma ferramenta que pudesse ser utilizada para organizar atividades do dia a dia, como:

- Trabalhos escolares;
- Exercícios;
- Compromissos;
- Tarefas domésticas;
- Atividades de projetos.

---

## Funcionamento

O site permite que o usuário digite uma nova tarefa e a adicione à lista.

Depois de cadastrada, a tarefa fica disponível na tela para que o usuário possa visualizar suas atividades.

Também foi implementado o armazenamento das informações utilizando o *TinyDB*, permitindo que as tarefas continuem salvas mesmo depois que o projeto seja fechado.

Entre as principais funcionalidades desenvolvidas estão:

- Adicionar novas tarefas;
- Visualizar as tarefas cadastradas;
- Selecionar uma tarefa;
- Excluir uma tarefa selecionada;
- Apagar todas as tarefas;
- Salvar as tarefas no armazenamento;
- Recuperar as tarefas salvas;
- Manter as informações disponíveis após fechar e abrir novamente.

O projeto também passou por testes durante o desenvolvimento para encontrar e corrigir problemas no funcionamento das tarefas e dos botões.
